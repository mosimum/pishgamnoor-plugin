استودیو نور سه‌بعدی پیشگام نور؛ نمایش محصولات با شورت‌کد، مدیریت محصولات و تنظیمات ظاهری.

== Description ==

Pishgamnoor Studio یک پلاگین اختصاصی برای صنایع روشنایی پیشگام نور است.

قابلیت‌ها:

* استودیو سه‌بعدی ۱۰ محصول با Three.js
* چرخش ۳۶۰ درجه، تغییر رنگ بدنه، دمای رنگ، شدت نور و روشن/خاموش
* نمایش با شورت‌کد `[pishgamnoor_studio]`
* مدیریت محصولات با افزودن، ویرایش و حذف
* فیلدهای کامل محصول: مدل سه‌بعدی، خانواده، توضیح، لینک، تصویر، رنگ‌ها، CCT و مشخصات
* تنظیمات ظاهری: رنگ‌ها، فونت، اندازه فونت، گردی گوشه‌ها، ارتفاع استیج و پنل
* نمایش/مخفی کردن کنترل‌ها
* تمام‌صفحه با fallback برای iframe
* ساختار کلاس‌محور و قابل توسعه برای محصولات و مدل‌های آینده

== Installation ==

1. فایل ZIP پلاگین را از بخش Releases دانلود کنید.
2. در پیشخوان وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید.
3. فایل ZIP را بارگذاری و فعال کنید.
4. از منوی «اختصاصی پیشگام نور» تنظیمات و محصولات را مدیریت کنید.
5. شورت‌کد `[pishgamnoor_studio]` را در برگه یا ویجت المنتور قرار دهید.

== Frequently Asked Questions ==

= آیا می‌توانم چند استودیو در یک صفحه داشته باشم؟ =
در نسخه ۱.۱ برای پایداری شناسه‌های DOM و رندر WebGL، در هر برگه یک نمونه نمایش داده می‌شود.

= محصولات کجا ذخیره می‌شوند؟ =
در پست تایپ اختصاصی `pn_product` و متا فیلدهای آن.

= آیا فایل‌های سه‌بعدی از CDN لود می‌شوند؟ =
نه. Three.js، فونت‌ها و تصاویر محصولات به‌صورت محلی از خود پلاگین لود می‌شوند.
